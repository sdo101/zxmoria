# the colours of things on the map, ours, not Moria's: create-data.ps1 reads this and gives every colour used a pair of
# its own in the tilemap's palette (from pair 16 up, the first 16 are the screen's own, see load.bas), and each
# creature and object the attribute byte of its colour (byte 50 of a creature's record, 59 of an object's), and each
# flavour (the shuffled names of potions, mushrooms, staffs, wands, rings and amulets) one in the game tables page
# sdo's rules (21 October 2026): every object coloured on its own wherever its name gives a colour, the others a colour
# for their class; every creature coloured from its name wherever there is one, the others red as before; an
# invisible creature, when it can be seen at all, pale grey; nothing here changes how the game plays
# the lines, fields between | marks, case does not matter, # starts a comment:
#   colour   | name | red green blue, each 0 to 7, the Next's 9 bit colour
#   creature | a word or words in a creature's name | colour            the longest that is in the name wins
#   object   | category (TV_...) or * | a word or words in its name | colour    the longest wins, a category first
#   class    | category (TV_...) | colour                              for an object no word above names
#   flavour  | list | flavour | colour                                 every flavour of the six lists must be here
#   invisible| colour
# the colour "none" leaves a thing to the map's own rules in s_core_map_put() (core.bas), a # white as the walls
